# 模板 C：优化指南型

> 适用：围绕一个性能/工程问题，逐层拆解优化方案（如 java-startup-optimization 系列）

---

## 系列组织

```
{series-slug}/
├── index.md
├── 01-{问题定义}.md          # 首篇：定义问题 + 根因分析
├── 02-{优化方向A}.md         # 中间篇：逐个方案拆解
├── 03-{优化方向B}.md
├── ...
└── 0N-{最佳实践与展望}.md    # 末篇：汇总 + 选型建议
```

**关键设计：首篇定义问题，中间篇逐个拆解方案，末篇收束选型。篇与篇之间有明确的前后引用。**

## 配图要求

| 位置 | 类型 | 内容 |
|------|------|------|
| §0 或 §1 | PNG / SVG | 数据对比图 / 问题现象可视化 |
| §2 | SVG | 优化原理流程图 / 内存布局图 / 时间线 |
| §3（可选） | PNG 截图 | 实际效果/控制台输出 |

---

## 写作要点

- **首篇定调**：用反直觉数据或对比开场，建立"这个问题值得解决"的共识
- **每篇承上启下**：`## 0 写在前面` 回顾前篇结论 + 引出本篇问题
- **数据驱动**：优化前/后对比表是标配
- **末篇收束**：汇总所有方案，给出"什么场景选什么"的决策树
- **篇间引用**：用"（二）""（三）"或相对链接互相引用
- **标注版本**：优化方案往往有版本限制，必须标明

---

## 系列首篇 vs 中间篇 vs 末篇的差异

| 维度 | 首篇 | 中间篇 | 末篇 |
|------|------|--------|------|
| `## 0` 标题 | 写在前面 / 反直觉事实 | 承上启下式 | 回顾全系列 |
| 重心 | 定义问题 + 根因 | 单个方案拆解 | 汇总选型 |
| 数据 | 问题有多严重 | 方案有多有效 | 全景对比 |
| 配图 | 现象/排行 | 原理/流程 | 决策树/分层 |
